A dark, athletic block theme for fitness sites.

== Description ==

Fitbull is a block theme for fitness, training and nutrition sites. It has a dark design with bold condensed headings, a lime accent, and patterns for a homepage hero, content hubs, an article grid and a call to action.

The theme works on its own as a blog theme. Install the companion plugin, ArponSamanta Fitness Toolkit, to add the exercise library, workout plan generator, recipes and meal planner, calculators, progress log, and gear and supplement guides. The theme includes templates and styles for those content types.

== Installation ==

1. In your dashboard, go to Appearance > Themes and click Add New.
2. Search for "Fitbull", then click Install and Activate.
3. Optional: install the ArponSamanta Fitness Toolkit plugin and use Tools > Fitbull demo content to load sample content.

== Frequently Asked Questions ==

= Does the theme need the plugin? =

No. Without ArponSamanta Fitness Toolkit the theme is a complete blog theme. Sections that rely on the plugin are hidden.
