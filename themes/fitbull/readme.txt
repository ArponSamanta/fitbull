A dark, athletic block theme for fitness sites.

== Description ==

Fitbull is a block theme for fitness, training and nutrition sites. It has a dark design with bold condensed headings, a lime accent, and patterns for a homepage hero, content hubs, an article grid, a call to action and a disclaimer note.

To build a homepage, create a page, choose the "Landing page" template, and set it as your homepage under Settings > Reading. Posts, comments and search use the standard templates.

The theme works on its own as a blog theme. Install the companion plugin, ArponSamanta Fitness Toolkit, (https://wordpress.org/plugins/arponsamanta-fitness-toolkit/) to add the exercise library, workout plan generator, recipes and meal planner, calculators, progress log, and gear and supplement guides. The plugin provides the templates for those content types, and the theme styles them.

== Installation ==

1. In your dashboard, go to Appearance > Themes and click Add New.
2. Search for "Fitbull", then click Install and Activate.
3. Optional: install the ArponSamanta Fitness Toolkit plugin and use Tools > Fitness Toolkit demo content to load sample content. The importer also creates a Home page that uses the Landing page template.

== Frequently Asked Questions ==

= Does the theme need the plugin? =

No. Without ArponSamanta Fitness Toolkit the theme is a complete blog theme. Sections that rely on the plugin are hidden.
